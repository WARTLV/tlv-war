# מצב הפרויקט בפועל

## עובד כעת

- מסך פתיחה/בחירת דמות עם שישה כרטיסים.
- roster מרכזי ב־`game-v2.js`: סטטים, שם ספיישל ומיפוי אנימציות לכל לוחם.
- HUD דינמי לפי הדמות שנבחרה.
- בקרי מגע: D-pad, אגרוף, בעיטה, קפיצה, הגנה וספיישל.
- בעיטה, קפיצה, uppercut וספיישל מנגנים רצפי פריימים במקום אותה תמונת אגרוף.
- damage בתקיפות המחוברות ניתן בפריים הפעיל פעם אחת.
- שליח כחול מגיע מימין לשמאל כל 12 שניות; בארבע הפעמים הראשונות מופיעה הוראת “קפוץ”.
- collision השליח מחושב מרחבית לפי X וגובה הקפיצה.
- שש תיקיות מהלכים הועתקו ל־`assets/roster-frames/`.
- `node --check game-v2.js` עבר לאחר השינויים האחרונים.

## אינו גמור / בעיות ידועות

- אין state machine מלא. עדיין יש booleans ופונקציות override בסוף `game-v2.js`.
- המנוע משתמש ב־`setInterval` ולא fixed-step `requestAnimationFrame`.
- אין wave system אמיתי או כמה אויבים במקביל; יש enemy יחיד.
- אין startup/active/recovery מלא לכל פעולת אויב, hitstop, hitstun, knockdown או invulnerability עקביים.
- camera עוקבת כמעט תמיד; אין dead-zone מקצועי.
- אין walk cycles לחמש דמויות ואין walk-back לאף אחת.
- מחזור walk של BIG.COM אינו מאושר: F06 גורם לקפיצת סילואט של כ־67px.
- idle של כל שש הדמויות נמצא בקנבסים לא אחידים.
- T.M.R והשופט כוללים קבצים עם סיומת `.webp` אך תוכן PNG.
- הרקע בנוי בעיקר CSS גיאומטרי ואינו ברמת היעד.
- אין pause מלא, defeat screen, settings, onboarding מלא או remapping.
- יש שרשרת של תשעה קובצי CSS; יש לאחד אותם רק לאחר ייצוב ה־UI.
