# TLV WAR — Rothschild Rumble · START HERE

עודכן: 16 באוגוסט 2026

זהו מסמך הכניסה הקנוני לצ'אט או לצוות חדש. המשחק הוא beat-'em-up דו־ממדי למובייל במצב landscape, בהשראת קצב המשחק של Little Fighter ומשחקי ארקייד מסוף שנות ה־90, אבל עם שפה מקורית של WAR TLV ושדרת רוטשילד.

## מה לבנות

השחקן בוחר אחד מששת לוחמי WAR TLV, מתקדם לאורך שדרת רוטשילד, מביס בריוני רחוב חלשים ולאחר מכן ארבעה בוסים. שליח כחול על אופניים חולף בשביל האופניים כל 12 שניות ומהווה מכשול שחייבים לקפוץ מעליו. המשחק מיועד קודם כול לטלפון לרוחב.

## מצב נוכחי

- תיקיית runtime קנונית: `outputs/rothschild-rumble-game/`
- קובץ כניסה: `index.html`
- מנוע פעיל: `game-v2.js?v=8`
- עיצוב נטען בשכבות: `style.css` עד `style-v8-select.css`
- בחירת שש דמויות קיימת ומחוברת למנוע.
- לכל שש הדמויות יש מיפוי ל־punch, kick, uppercut, jump ו־special.
- BIG.COM הוא היחיד עם מחזור walk-forward בן 6 פריימים. אין walk-back לאף דמות.
- הרקע עדיין CSS בסיסי ואינו עומד ביעד האמנותי.
- מנגנון הקרב עובד, אך עדיין אינו state machine מלא ואינו מוכן להגדרת “משחק גמור”.

## כללי ברזל

- אין להשתמש בלוגו WWE או בסימני ליגה קיימים. חגורת T.M.R חייבת להיות אליפות גנרית בזהב מיושן.
- לא משנים זהות, פנים, גוף, תלבושת או אביזרי דמות בין פריימים.
- כל cutout: PNG RGBA שקוף ונקי, ללא glow/CRT/צל/FX baked-in.
- כל דמות פונה ימינה בלבד; המנוע מבצע mirror לשמאל.
- כל פריימי אותה דמות על קנבס קבוע, root anchor אחיד וקו קרקע משותף.
- יעד master לאנימציות: 768×1024, root x=384, ground y=972.
- אין להשתמש בשירות או API חיצוני בתשלום. עד כה העבודה בוצעה בכלים המקומיים/המובנים בלבד.

## פרומפט מוכן לצ'אט הבא

> פתח את `outputs/rothschild-rumble-game/HANDOFF/START-HERE.md` וקרא את כל ששת המסמכים המקושרים לפני כל שינוי. המשך מתוך תיקיית `rothschild-rumble-game` בלבד כמקור runtime. אל תדרוס נכסים קיימים ואל תשתמש בשום שירות בתשלום. קודם אמת את מצב הקוד והנכסים, אחר כך בצע את משימת P0 הראשונה מתוך BACKLOG.md, בדוק בדפדפן במידות 667×375, 844×390 ו־932×430, ורק אז מסור קישור לבדיקה.
